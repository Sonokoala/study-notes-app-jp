# Study Notes JP

授業・チュートリアル・勉強会の録画や、授業資料のスクリーンショットから、学習用の資料を作る Windows 用のアプリです。
英語で学んでいる日本語話者のために作りました。
作るファイルはすべてダークテーマの PowerPoint です（「設定」で PDF も作るようにできます）。

| 作るもの | 中身 |
|---|---|
| 4分割の学習ノート（日本語） | 左上：図解。右上：キーコンセプト（赤字）。左下：英語の専門用語と、カタカナの発音（強く読む所は太字＋下線）、日本人がつまずきやすい点のコツ、和製英語の注意。右下：具体例とたとえ話。 |
| プレゼン（英語） | 短い英語のスライドと、ノート欄に読み上げ用の英語の原稿。原稿は1行1文（一息で読める長さ）で、強く読む語は太字。英語で話す練習に使えます。 |

英語版は [study-notes-app](https://github.com/Sonokoala/study-notes-app) です（ノートもプレゼンも英語）。

## インストール

インストーラーはありません。このリポジトリのコードをそのまま動かすので、何をしているかを先に読んで確かめられます。

1. https://www.python.org/downloads/ から Python 3.11 以降をインストールします。インストール画面で **Add python.exe to PATH** にチェックを入れてください。
2. このコードを手に入れます。緑の **Code** ボタン > **Download ZIP** でダウンロードして展開するか、`git clone` します。
3. `setup.bat` を一度だけダブルクリックします。このフォルダの中に `.venv` フォルダを作り、`requirements.txt` のライブラリをそこに入れます。PC のほかの部分には影響しません。
4. `start.bat` をダブルクリックすると、アプリが開きます。

アンインストールするときは、このフォルダを削除します（設定も消す場合は `%APPDATA%\StudyNotesJP` も削除します）。

## 使い方

1. 「**設定**」タブで、使う AI を選び、API キーと保存先のフォルダを入力して「保存」を押します。
   - Gemini: https://aistudio.google.com/apikey で無料の API キーを取得できます（無料枠では、送った内容が Google の製品改善に使われることがあります）。モデルは無料枠で使える `gemini-3.5-flash-lite`（既定。速くて軽い）、`gemini-3.8-flash`、`gemini-3.6-flash`、`gemini-3.1-flash-lite` から選べます。長い講義でノートが途中で切れるときは `gemini-3.8-flash` を試してください。
   - Claude、ChatGPT: 使った分だけ課金されます。
   - Ollama: https://ollama.com をインストールし、画像を読めるモデルを追加します（例: `ollama pull gemma3:12b`）。無料で、データはこの PC の外に出ません。
2. 「**作成**」タブで、録画（mp4、m4a、wav など）、文字起こし（.txt）、またはスクリーンショット（複数可）を選びます。
3. 「**監視フォルダ**」タブでフォルダを追加すると、新しく入ったファイルを自動で処理します。スクリーンショットは、最後の1枚が入ってから5分後にまとめて処理し、処理した画像は `done\<日時>` に移します。

文字起こしは、Whisper を使ってこの PC の中で行います（初回だけモデルをダウンロードします）。PDF は既定では作りません。作る場合は「設定」の「PDF も作る」にチェックを入れます（PowerPoint が必要です）。

保存されるファイルの例:

```
<保存先>\<科目>\2026-10-22 MCPのしくみ - 学習ノート.pptx
<保存先>\<科目>\2026-10-22 MCPのしくみ - プレゼン_EN.pptx
<保存先>\<科目>\2026-10-22 MCPのしくみ - 文字起こし.txt
```

設定とログは `%APPDATA%\StudyNotesJP` に保存されます。API キーもここに保存されるので、このフォルダは人に渡さないでください。

## 発音練習アプリとつなぐ（使う人だけ）

用途に合わせて選べます。

- **ノートだけ欲しい人：** 何も設定しなくて大丈夫です。今まで通り、学習ノートと英語のプレゼンを作ります（「作るもの」で英語のプレゼンを外すこともできます）。
- **英語で発表する練習までしたい人：** 発音練習アプリ [Pronunciation Coach](https://github.com/Sonokoala/pronunciation-coach) とつなぎます。英語のプレゼンの読み上げ原稿を声に出して読むと、Microsoft Azure が音ごとに採点し、日本語でコツを表示します（Azure の料金については Pronunciation Coach の README を見てください）。

つなぎ方:

1. Pronunciation Coach をダウンロードして、README の通りに Azure のキーを設定します。
2. このアプリの「**設定**」タブの「**発音練習との連携**」で、「英語のプレゼンを発音練習アプリに入れる」にチェックを入れ、Pronunciation Coach のフォルダ（`server.py` があるフォルダ）を選んで「保存」を押します。
3. あとは録画を処理するだけです。英語のプレゼンは Pronunciation Coach の `decks\<科目>\` に保存され、「プレゼンを作り終えたら、発音練習アプリを開く」にチェックがあれば、そのまま発音練習の画面が開きます。
   「作成」タブの「**発音練習を開く**」ボタンでも、いつでも開けます。

## 開発

```
setup.bat                          # または: python -m venv .venv && .venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python run.py        # エラーを確認できるコンソール付きで起動する
```

`app/pipeline.py` が処理の流れ、`app/llm.py` が各 AI の呼び出し、`app/prompts.py` が AI への指示文、
`app/builders/` が PowerPoint の作成、`app/watcher.py` がフォルダの監視を担当します。
